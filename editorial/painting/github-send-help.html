Разрешить отправку заданий

Ключ создаётся вами на GitHub. Не присылайте его в чат. Вводите его только в поле отправки редактора на kameralog.github.io.

  1. Сначала сделайте резервную копию в редакторе.
  2. Откройте создание fine-grained ключа. GitHub может попросить войти или подтвердить пароль.
  3. Resource owner: kameralog. Срок: 7 дней.
  4. Repository access: Only select repositories. Выберите только kameralog.github.io. Не выбирайте все репозитории.
  5. Repository permissions → Contents: Read and write. Metadata: Read-only. Другие права не нужны.
  6. Нажмите Generate token и скопируйте показанный ключ.
  7. Вернитесь в панель, нажмите «Отправить копирайтеру», подготовьте предпросмотр. Вставьте ключ в поле, проверьте состав и подтвердите запись.

Токен даёт право изменения содержимого всего выбранного репозитория, не только папки входящих. Не используйте его на неизвестных сайтах. Отозвать его можно на странице ключей GitHub.

Приложение не сохраняет ключ в localStorage или резервных копиях и очищает поле при отправке или закрытии окна. Во время отправки ключ доступен коду этой страницы; это не серверное хранилище секретов.

Синопсисы и замечания записываются в публичный репозиторий. Личные сведения и секреты в задания не добавляйте. Кнопка не публикует статьи и не меняет карточки игры.

Если сеть оборвалась, используйте проверку незавершённой отправки. Приложение проверит тот же файл, а не создаст новый пакет. Успех подтверждается только после чтения содержимого записанного коммита.

Отправка из приложения работает после вашего клика; она не запускает ассистента автоматически. Пакет доступен ему при следующем чтении репозитория.
